# moc WebUI 设计语言

本文记录 moc WebUI 的审美取向与视觉规范，是改动界面前必须读的约束。
组件选型见 `agents.md`；令牌的唯一来源是 `src/index.css`，本文只解释意图与用法，数值以 CSS 为准。

## 1. 品味

视觉基准是 Devin 工作台的低对比灰阶、内嵌主舞台和紧凑浮层。moc 只保留一列会话栏，搜索与收起放在栏头，设置与插件放在底部，不设独立导航轨。

目标气质：**高端、大气、优雅、克制**。像一件做工好的工具，而不是一张信息海报。

### 1.1 核心原则

1. **安静优先**：界面退到内容后面。灰阶承担几乎所有信息层级，强调色只出现在「选中、链接、进行中」。
2. **发丝轮廓**：层级靠面的明暗差与柔影区分。窗框分区、输入卡和需要确认的卡片可加发丝轮廓（`border-subtle` / `border`），不用颜色加粗外框。
3. **静态的形**：控件的几何外观不随状态跳变。聚焦、悬停不加粗边框、不加外圈、不位移；悬停最多改文字色或给一层极淡底色。
4. **只显示有区分度的信息**：几乎所有选项都具备的能力（如「支持思考」）不做徽标；只保留能区分彼此的指示（图片输入、上下文长度）。图标同理：与文字重复的图标删掉。
5. **对齐是底线**：同一列的文字左缘必须对齐；删图标时要整组删，不能只删一半导致错位。不同性质的内容用缩进或字号区分，不用颜色堆叠。
6. **原文与本地化分工**：会话工作区（活动流、工具视图、diff、终端、任务与子代理工作块）、思考强度（`off` `minimal` `low` `medium` `high` `xhigh` `max`）、动词与 1–2 词短标签、专有名词、命令名、模型 ID 与具体配置字段名一律保留英文原文；描述性正文、配置项说明、空态引导与错误提示走用户语言 i18n。
7. **少即是多**：不放按键提示条、装饰性图标、占位插画、无意义的圆点。用户能通过帮助找到的信息，不常驻在界面上。

### 1.2 明确不喜欢的

| 不要                                   | 改为                                         |
| -------------------------------------- | -------------------------------------------- |
| 聚焦时边框变粗 / 出现 ring             | 聚焦前后外观完全一致                         |
| 卡片、输入框用高对比实线勾边           | 底色差 + 中性发丝轮廓或贴身柔影              |
| 浮层用 `border` 勾边                   | `--elevation-popover` / `--elevation-dialog` |
| 悬停出现强烈背景色、字重变化           | 低对比灰阶底或只变文字色                     |
| 菜单项前的冗余图标、弹窗底部的键位提示 | 删除                                         |
| 琥珀、蓝等彩色大面积底色               | 灰阶面；彩色只做文字或 10% 淡底徽标          |
| 任意像素字号 `text-[13px]`             | 字号阶梯                                     |
| 把英文术语翻成中文（「高」「最大」）   | 保留原文                                     |

## 2. 色彩

**中性灰阶 + 单一强调色**。浅色基于 `#171717` 的透明度派生，深色基于白色透明度派生，叠在任何面上都能自然混色。

- 面的层级（由低到高）：`chrome`（外框）< `sidebar` / `panel` < `background`（主舞台）< `card` / `popover`。
  - 浅色：外框浅灰，侧栏和舞台近白，输入卡及浮层白色。
  - 深色：保留相同的明度阶梯；文字和焦点标记在每一级保持可见。
- 文字三级：`foreground` → `muted-foreground` → `text-tertiary`。过程信息、时间戳、元数据用 tertiary。
- 强调色 `brand`（浅 `#3b6ff5` / 深 `#6d97ff`）：选中、链接、进行中、品牌徽标。
- 语义色 `success` / `warn` / `destructive` 只用于文字、图标或 10% 淡底，不做大面积填充。
- 选区 `--selection` 与行内代码 `--inline-code-bg` 用半透明，避免不透明色块。
- 深色模式不是浅色反转：托盘 `--composer-tray` 在深色下要比卡片**更深**，否则层级会反过来。

## 3. 层级与阴影

不用实线描边，阴影令牌按高度递增：

| 令牌                         | 用途                                   | 构成                        |
| ---------------------------- | -------------------------------------- | --------------------------- |
| `--elevation-composer-inset` | 托盘内的白卡                           | 仅贴身软影                  |
| `--elevation-composer`       | 欢迎页单层输入卡等独立输入框           | 发丝轮廓 + 极淡贴身影，扁平 |
| `--elevation-popover`        | 菜单、下拉、补全、悬浮卡、回到底部按钮 | 发丝阴影环 + 软长投影       |
| `--elevation-dialog`         | 模态框                                 | 发丝阴影环 + 更长更散的投影 |

新增浮层一律复用上述令牌，不写新的 `shadow-[...]` 组合；需要新高度时先在 `index.css` 浅色、深色两处同时加令牌。

## 4. 字号

组件里只用七级字号，**禁止 `text-[Npx]`**：

| 类             | 尺寸 | 用途                        |
| -------------- | ---- | --------------------------- |
| `text-2xs`     | 11px | 徽标、计数、kbd、分组小标题 |
| `text-xs`      | 12px | 次要说明、元信息            |
| `text-ui`      | 13px | 菜单项、列表行、控件、侧栏  |
| `text-sm`      | 14px | 标题行、普通正文            |
| `text-chat`    | 14px | 对话正文、用户气泡、输入框  |
| `text-title`   | 15px | 区块标题                    |
| `text-heading` | 17px | 弹窗标题                    |
- 新增阶梯名必须同时登记到 `src/lib/utils.ts` 的 `cn` 配置，否则会被当成颜色类合并掉。
- 字重克制：正文 400，标题与选中项 500–600，不用 700 以上（logo 例外）。
- 字体：`Inter Variable` + 中文系统字体；等宽用系统等宽栈（SF Mono / Cascadia Mono / Consolas），不打包几何感强的宽等宽字体。
- 正文 14px / 1.65，段距 0.7em，标题只比正文大一到两级，列表项几乎不留额外间距。

## 5. 形状与间距

- 圆角随尺寸递增：小控件 `rounded-md`/`rounded-lg`，菜单与卡片 `rounded-xl`，模态框 `rounded-2xl`，输入框托盘 22px / 卡片 16px，用户气泡 18px，主按钮圆形。
- 嵌套圆角要同心：外层半径 = 内层半径 + 内边距（输入框托盘 22px = 卡片 16px + `p-1.5`）。
- 菜单项紧凑对齐；侧栏行 36px、14px；会话列表为 44px 双行（13px 标题 + 12px 时间/状态，行间隔 2px；中文字面比拉丁字母显大，元信息须比标题小一级以上才分得出层级），「更多」按钮悬停时浮在标题行尾，右键弹出同一组操作；操作菜单在悬停、键盘聚焦和触屏下可用；会话头 `h-12`，底部不画分割线。
- 最左侧标签栏（52px，坐在 `chrome` 上）：上方为会话 `/`、Image Playground `/image-playground`、插件 `/plugins` 三个页面标签，下方为设置与折叠；折叠只收起相邻侧栏，标签栏常驻。侧栏底部放绿点 + moc 连接状态，不画分割线。
- 中文字重：`moc CJK` 字面把中文 ≤500 一律落到 Regular，≥600 落到约 Medium（苹方钳到 wght 510，雅黑用 Bold），并关闭伪粗体；中文靠清晰分层，不靠加粗。
- 图标：lucide 全局 `stroke-width: 1.5`；标签栏图标 20px。
- 选中态统一：白底上用无描边的浅灰底（`bg-accent`）表示选中，分段切换不再用灰色轨道 + 白色浮起块；描边按钮不加投影。

- 滚动条细而半透明，指针进入滚动区才显现（类 macOS 浮层滚动条），代码卡、diff 卡底部不常驻灰条；规则在 `@layer base`，局部 `[scrollbar-width:none]` 可覆盖。
- 增删统计统一用 `DiffStat`：`+N` 与 `−M`（U+2212 减号，与加号等宽）；与正文同行时加 `font-sans` 并取所在行字号。
- 变更类文件卡片显示相对会话目录的路径，目录先截断、文件名完整保留。
- 对话列宽 `min(768px, 100cqi - 48px)`，输入框与正文同宽（`.moc-chat-column`）。
- 图标用 lucide，描边 1.75px，常规 `size-4`，辅助 `size-3.5`。

## 6. 关键组件

### 输入框（composer）

- 欢迎页：左齐品牌标题、单层输入卡、状态与目录入口构成居中窄列，最大宽度 688px。会话页：输入卡嵌在灰托盘（`--composer-tray`，纯色无描边无投影，只靠底色与白卡区分），顶部保留状态条，待发队列排在其后。
- 状态条（36px、13px）文字与输入文字左右对齐（距托盘边 22px）。三种状态：有待办时左侧任务进度（可展开列表）、右侧本会话改动 chip（文件数 +/−）；无待办但有改动时左侧「✎ N files changed +/−」（14px、与 +/− 同字体同基线），右侧不放按钮；都没有时左侧「Tips:」+ core 下发的随机 tip，进入会话与发送消息时换一条；放不下时右缘渐隐，悬停后匀速平移到末尾。子代理数、会话费用始终排在最右，各自有值才出现。变更入口点击切到变更分页；会话页输入框不放占位文案；子代理与费用点击弹起对应 Popover（不离开对话区），上下文圆环同理弹简略上下文 Popover（占用条 + 各分块与 Free space 的 token 和窗口占比；每次模型请求结束、工具结果写入、压缩与模式/模型切换后合并重读 `session/context`，圆环即时更新），底部 Details 再进大尺寸 Context 模态；两处都不放手动压缩，压缩只走 `/compact`。不放快捷键提示、cwd/分支（会话头已有）和运行态。
- 输入卡常态用中性发丝轮廓，点击输入不改变轮廓。状态描边 `ring-warn/50` 表达 `!` 命令模式而非焦点。
- 点击卡片空白处聚焦输入；拖拽文件时外层出现 `ring-brand/40`。
- 发送按钮：`size-8` 圆形、`bg-foreground` 反色，禁用时降为 tertiary。会话运行中且有草稿时拉长为 `ButtonGroup` 分体胶囊：左半 secondary 浅灰底 + 列表加号图标，排队（Ctrl+Enter）；右半保持主色箭头，按「运行中发送」偏好补充或中断（Enter）。开启「Queue on Enter」后两键互换（Enter 排队、Ctrl+Enter 补充或中断），按钮位置不变，tooltip、占位文案与快捷键列表随之改写。两半与空闲发送按钮都用 tooltip 标注动作与快捷键。Shift/Alt+Enter 换行。
- Plan chip（`bg-brand/10 text-brand`）只在 plan 模式下出现，点击退出；入口是 `/plan` 与 Alt+J。`/plan` 补全选中或其后键入空白即切换（再输一次退出），命令不留在输入框，其后文字保留为草稿。
- 图片附件：40px 方形缩略图（`object-cover` 铺满、`rounded-lg`、发丝 ring），点击放大；删除是 20px 灰阶浮起圆钮（`bg-popover` + `--elevation-popover`，muted 图标，悬停变正文色），骑在右上角外凸 6px，悬停、键盘聚焦或触屏时出现，缩略图间距 12px 保证徽标不压邻图。

### 浮层

- 菜单、下拉、右键菜单、`/` 与 `@` 补全统一：`rounded-[10px] bg-popover/95 backdrop-blur-md p-1 shadow-[var(--elevation-popover)]`，无 border；菜单项 `rounded-md`，图标 muted。
- 补全对齐输入文字一侧，欢迎页向下、会话页向上优先，空间不足时翻转；说明取当前高亮项，不夺取输入焦点。命令名不截断，参数提示让出剩余宽度；底部详情区给出完整的命令 + 参数与说明，各项叠放在同一格、高度取最高一项，切换高亮时不跳动。
- Context 模态的消息目录：每条前的小圆点按来源着色（用户输入 `chart-1`、模型输出 `chart-5`、工具结果与手动命令 `chart-6`、运行时注入等合成消息 `chart-7`、其余 `chart-3`），标题后跟线上 role 的等宽灰徽标；目录顶部有临时开关隐藏不可展开的工具结果。正文里的工具调用渲染为卡片（工具名、call id、逐项参数），不显示协议原始 JSON。
- 分隔线 `bg-border-subtle`；分组标题 `text-xs font-medium text-muted-foreground`（补全里用 `text-2xs text-text-tertiary`）。
- 选中标记用 `muted-foreground` 的勾，不用强调色。
- 模态框 `rounded-2xl p-6`，标题 `text-heading`，描述 `text-ui text-muted-foreground`。

### 模型选择器

- 触发器只显示「模型 · 思考强度」，不带下箭头。
- 浮层是可搜索列表：顶部「Recent」列出 core 记录的最近使用（完整 selector，条数由 `[models] recent` 配置，搜索时隐藏），其后是组合与按供应商分组的模型。详情卡是锚在高亮项旁的独立浮层，与该行顶端对齐，优先在列表右侧、放不下时翻到左侧，行滚出列表时隐藏；展示上下文、输出上限、图片输入、思考强度、Fast Mode 与价格。
- 只显示模型真有的信息：Fast Mode 开关只在模型配置 `fast_mode = true` 时出现；价格只在配置了 `pricing` 时出现，缺失就整段隐藏，不写「未知」。

### 徽标

- 用 `Badge variant="brand"`：`text-2xs`、`bg-brand/10 text-brand`。颜色随状态变化的才允许手写。

### 对话转写

- 用户消息：右对齐灰色气泡 `bg-bubble`，无边框。
- 助手正文直接落在主舞台上，不套卡片。
- 过程（思考、工具调用）默认折叠成一行「Worked X +N −M」，不附活动摘要（+N −M 为该段全部工具含子调用的改动行数，复用 `DiffStat`，与「Worked」同字体同字号共用基线、降到 75% 不透明度，无改动不显示），展开后左侧一条 `border-border-subtle` 发丝线收纳，发丝线对准 chevron 中心，子行文字与「Worked」左缘对齐。中间正文把过程切成多段「Worked」：进行中的轮次收起已被正文收尾的段，当前段保持展开；轮次完成后整体再收进一行外层「Worked」（时长与内层同一口径，算到最终回复开始），只露出最后一段正文，展开外层后各段仍折叠、中间正文可见（没有中间正文时直接列出活动行）。计划卡、告警、交付结果与任务通知始终显示在折叠之外。展开后滚动时过程标题钉在顶端，内层标题叠在外层之下，子活动标题再叠其下；点击钉住的标题收起时，把标题滚回视口顶端。顶层活动行悬停时在正文列左外侧固定槽显示发生时刻（tertiary `text-2xs`，各级缩进对齐到同一槽），主舞台不足 56rem 时不显示。回到底部按钮 `z-30`，压在钉住标题之上。悬停只变文字色，不出现底色块。
- 活动行只有文字：整行同一档 tertiary 灰（动作与对象同色，悬停整行提到 muted），比「Process」标题低一级；常态不放图标，不用等宽字体，也不开 `tabular-nums`（Inter 的 tnum 会把路径与命令里的连字符撑宽）。动作用英文短动词（`Read` / `Edit` / `Write` / `Run` / `Search`），名词由对象本身说明。文件类对象（`Read` / `Edit` / `Write`）只显示文件名与行范围，完整路径放悬停提示。失败时动词染成 destructive，告警图标跟在对象后面，行首不插图标，保证整列动词左缘对齐。

### 文件面板

- 右侧检查面板的默认分页；宽 ≥640px 时左树右编辑区并排（树宽 200–360 可拖，默认 240），更窄时编辑区替换树、头部给返回按钮。
- 宽屏时检查面板是窗框里独立的一张圆角卡片（`bg-background` + `--elevation-ring` 发丝轮廓），与主舞台之间留 4px chrome 缝；标签带 3.5 号 lucide 图标，选中 `bg-accent`，标签条下不画分隔线，右端是面板开关（主舞台头部此时隐藏同一开关）。
- 标签条末尾 `+` 打开「New tab」（`launcher` 分页）：居中搜索框（同 composer 柔影）+「Panels / Tools」两组 32px 行，行内图标 muted、说明 tertiary；回车打开首个命中项。
- 文件工具栏左侧是根目录下拉（工作区显示目录名 / `Session`），不用分段控件；工具栏下与树右侧各一条 `border-border-subtle`。
- 树行高 26px、`text-ui` 正文色、每级缩进 12px，行左右各缩 6px 并带 `rounded-md`：悬停 `surface-hover`、选中 `bg-accent`；目录只留 chevron，不放文件夹图标，文件按扩展名映射少量 tertiary lucide 图标；agent 改过的文件行尾一个 brand 小圆点。
- 会话空间命名空间（`plans` / `jobs` / `archive` / `history` / `skills`）显示英文标签，行尾用 tertiary 等宽字回显原始 URI；整体只读。
- 文件头部的路径是 sans 面包屑：细箭头分隔，前段 muted、末段正文色。
- 编辑区标签条复用「选中 `bg-accent`、未选中悬停浅底」的语言：预览标签斜体、未保存一个 brand 圆点、× 只在悬停浮现。
- CodeMirror 主题从令牌派生（系统等宽字体、tertiary 行号、gutter 无描边、当前行极淡底色、选区 `--selection`、光标 brand）；Markdown 默认渲染 `.moc-prose` 预览，可切源码。

### 终端

- 终端分页整体懒加载（xterm 不进主包）。标签条复用文件标签的同一形态：标签名是 shell basename，非根 cwd 追加相对目录，已退出条目降为 tertiary 并显示退出码。
- xterm 视觉完全从令牌派生：背景与面板一致、光标 brand、选区 `--selection`；ANSI 16 色深浅各调一套，低饱和克制。容器只留内边距，不加边框。
- 快捷键 ``Ctrl+` ``：面板未开或不在终端分页时切过去，已在终端分页时收起面板。

### 工具与思考块

- 每个活动是一行 26px（`h-6.5`）标题：动词 + 目标（同为 tertiary，单行截断）+ 尾注（耗时、数量、`+N −M`）。工具的尾注靠左紧跟目标与范围，普通目标和尾注同用 tertiary；长目标截断时仍保留尾注空间，单卡、嵌套与合并组一致，操作按钮放在尾注之后。其他活动保留右侧尾注。没有卡片外框，也不加状态色描边；运行中靠动词脉冲表达，失败时动词、尾注前的警示图标与错误行染成 `destructive`。
- 正文落在标题下方，和标题文字左对齐。容器统一用 `rounded-xl bg-code`，不加描边；终端、带行号代码、diff、grep 分组都放在这种灰底卡里，等宽 `text-xs`，行号槽和元信息用 tertiary。
- 工具全局预设只有 `Hidden` / `Brief`，`Ctrl+O` 在两者间循环：`Hidden` 常规只留标题，警告与通知始终显示正文，不放右侧提示/警告标记。`Brief` 按工具给少量预览：`Read` / `Search` 不显示原始正文，bash 取末尾 4 行，diff 最多 6 行，todo 最多保留前三项、后两项且不因完成而隐藏。完整结果由单条点击展开，仍受 core 输出预算约束；切换全局预设收回手动展开，通知不受折叠影响。
- 同一次读取的长行省略合并为一条「`N long lines omitted`」摘要，可独立展开行号与续读方式；不逐行常驻刷屏。父调用已展示的相同通知不再重复出现在子调用，独有警告与失败状态不隐藏。原始结果不因展示去重而改写。
- 简略档的思考在流式时只露末尾几行，顶部用 mask 渐隐，不用分隔线。
- 同批次连续的同名只读工具合并成一行「`Read N files`」，展开后再逐个列出。

## 7. 正文排版（`.moc-prose`）

对话正文、思考内容、计划正文共用一套规则，元素通过 `data-streamdown` 标记命中样式；新增 Markdown 渲染场景必须复用 `.moc-prose`，用 `--moc-prose-size` 调字号，不另写排版。

- 正文 14.5px / 1.75 行高；标题无下边框，字间距 -0.01em。
- 行内代码：半透明底、4px 圆角、0.88em 等宽，跨行时 `box-decoration-break: clone`。
- 代码块：灰底大圆角，无语言头、无行号、无边框；复制按钮悬停才出现。
- 表格：只留水平发丝线，表头透明底、中等字重、次级色，首末列贴边。
- 命令面板底部一条 36px 提示栏：`↑↓ Navigate / ↵ Select / Esc Close`，`Kbd` + tertiary 文字。
- 文件分页并排布局未打开文件时，编辑区居中列几条常用快捷键（tertiary 文字），代替空状态文案。
- 引用：2px tertiary 左线 + 次级文字色。

## 8. 动效

- 只做状态过渡：颜色、透明度、`box-shadow`，时长约 120–200ms。
- 浮层进出用淡入 + 轻微缩放（模态框 0.98）。
- 不做几何跳变或装饰动画；加载、工作流和会话运行只用轻量状态反馈，并尊重 `prefers-reduced-motion`。

## 9. 改动流程

1. 先查 `index.css` 有无可用令牌；没有就在浅色、深色两处同时新增，并写注释说明意图。
2. 组件里只用令牌类和字号阶梯，类名合并统一用 `@/lib/utils` 的 `cn`。
3. 浅色、深色都要截图确认，重点看对齐、层级是否反转、聚焦前后是否一致。
4. 提交前运行：`pnpm exec biome check src && pnpm exec tsc -b --noEmit`。
