# moc WebUI 设计语言

本文记录 moc WebUI 的审美取向与视觉规范，是改动界面前必须读的约束。
组件选型见 `agents.md`；令牌的唯一来源是 `src/index.css`，本文只解释意图与用法，数值以 CSS 为准。

## 1. 品味

参照对象：Devin、Claude Desktop、Codex Desktop、Cursor、Antigravity。只借它们的**设计语言与质感**，不照搬功能和整体布局；功能以 moc TUI 为准。

目标气质：**高端、大气、优雅、克制**。像一件做工好的工具，而不是一张信息海报。

### 1.1 核心原则

1. **安静优先**：界面退到内容后面。灰阶承担几乎所有信息层级，强调色只出现在「选中、链接、进行中」。
2. **不画线**：层级靠「面的明暗差 + 软阴影」区分，不靠实线边框。确需分隔时只用发丝线（`border-subtle` / `border`），且越少越好。
3. **静态的形**：控件的几何外观不随状态跳变。聚焦、悬停不加粗边框、不加外圈、不位移；悬停最多改文字色或给一层极淡底色。
4. **只显示有区分度的信息**：几乎所有选项都具备的能力（如「支持思考」）不做徽标；只保留能区分彼此的指示（图片输入、上下文长度）。图标同理：与文字重复的图标删掉。
5. **对齐是底线**：同一列的文字左缘必须对齐；删图标时要整组删，不能只删一半导致错位。不同性质的内容用缩进或字号区分，不用颜色堆叠。
6. **原文不翻译**：思考强度（`off` `minimal` `low` `medium` `high` `xhigh` `max`）、模型 ID、命令名、协议字段一律显示原文。界面文案用中文。
7. **少即是多**：不放按键提示条、装饰性图标、占位插画、无意义的圆点。用户能通过帮助找到的信息，不常驻在界面上。

### 1.2 明确不喜欢的

| 不要                                   | 改为                                         |
| -------------------------------------- | -------------------------------------------- |
| 聚焦时边框变粗 / 出现 ring             | 聚焦前后外观完全一致                         |
| 卡片、输入框外围一圈实线或发丝描边     | 底色差 + 贴身柔影                            |
| 浮层用 `border` 勾边                   | `--elevation-popover` / `--elevation-dialog` |
| 悬停出现整块背景色、字重变化           | 只变文字色                                   |
| 菜单项前的冗余图标、弹窗底部的键位提示 | 删除                                         |
| 琥珀、蓝等彩色大面积底色               | 灰阶面；彩色只做文字或 10% 淡底徽标          |
| 任意像素字号 `text-[13px]`             | 字号阶梯                                     |
| 把英文术语翻成中文（「高」「最大」）   | 保留原文                                     |

## 2. 色彩

**中性灰阶 + 单一强调色**。浅色基于 `#171717` 的透明度派生，深色基于白色透明度派生，叠在任何面上都能自然混色。

- 面的层级（由低到高）：`sidebar` / `panel` < `background`（主舞台）< `card` / `popover`。
  - 浅色：侧栏 `#fafafa`，主舞台纯白，侧栏与主舞台之间只有一条发丝线。
  - 深色：`#111113` < `#161618` < `#1c1c1f` / `#1f1f22`。
- 文字三级：`foreground` → `muted-foreground` → `text-tertiary`。过程信息、时间戳、元数据用 tertiary。
- 强调色 `brand`（浅 `#3b6ff5` / 深 `#6d97ff`）：选中、链接、进行中、品牌徽标。
- 语义色 `success` / `warn` / `destructive` 只用于文字、图标或 10% 淡底，不做大面积填充。
- 选区 `--selection` 与行内代码 `--inline-code-bg` 用半透明，避免不透明色块。
- 深色模式不是浅色反转：托盘 `--composer-tray` 在深色下要比卡片**更深**，否则层级会反过来。

## 3. 层级与阴影

不用实线描边，阴影令牌按高度递增：

| 令牌                         | 用途                                   | 构成                        |
| ---------------------------- | -------------------------------------- | --------------------------- |
| `--elevation-composer-inset` | 托盘内的白卡                           | 仅贴身软影                  |
| `--elevation-composer`       | 输入框外层                             | 贴身柔影 + 长投影，无描边   |
| `--elevation-popover`        | 菜单、下拉、补全、悬浮卡、回到底部按钮 | 发丝阴影环 + 软长投影       |
| `--elevation-dialog`         | 模态框                                 | 发丝阴影环 + 更长更散的投影 |

新增浮层一律复用上述令牌，不写新的 `shadow-[...]` 组合；需要新高度时先在 `index.css` 浅色、深色两处同时加令牌。

## 4. 字号

组件里只用七级字号，**禁止 `text-[Npx]`**：

| 类             | 尺寸   | 用途                        |
| -------------- | ------ | --------------------------- |
| `text-2xs`     | 11px   | 徽标、计数、kbd、分组小标题 |
| `text-xs`      | 12px   | 次要说明、元信息            |
| `text-ui`      | 13px   | 菜单项、列表行、控件、侧栏  |
| `text-sm`      | 14px   | 标题行、普通正文            |
| `text-chat`    | 14.5px | 对话正文、用户气泡、输入框  |
| `text-title`   | 15px   | 区块标题                    |
| `text-heading` | 17px   | 弹窗标题                    |
- 新增阶梯名必须同时登记到 `src/lib/utils.ts` 的 `cn` 配置，否则会被当成颜色类合并掉。
- 字重克制：正文 400，标题与选中项 500–600，不用 700 以上（logo 例外）。
- 字体：`Geist Variable` + 中文系统字体；等宽 `Geist Mono Variable`。

## 5. 形状与间距

- 圆角随尺寸递增：小控件 `rounded-md`/`rounded-lg`，菜单与卡片 `rounded-xl`，模态框 `rounded-2xl`，输入框托盘 24px / 卡片 20px，用户气泡 18px，主按钮圆形。
- 嵌套圆角要同心：外层半径 = 内层半径 + 内边距（输入框托盘 24px = 卡片 20px + `p-1`）。
- 菜单项 `rounded-lg px-2 py-1.5`；侧栏行高 `h-8`；会话头 `h-11`。
- 对话列宽 `min(768px, 100cqi - 48px)`，输入框与正文同宽（`.moc-chat-column`）。
- 图标用 lucide，描边 1.75px，常规 `size-4`，辅助 `size-3.5`。

## 6. 关键组件

### 输入框（composer）

- 两层结构：外层灰托盘（`--composer-tray`）始终存在，白卡嵌在其中。托盘顶部是固定 32px 的状态条（`h-7` + 托盘 `p-1`），有无待办都不变高；另外三边 `p-1`，用这圈灰边把输入框和白色页面分开。
- 状态条文字与输入文字左右对齐（距托盘边 24px）。左侧有待办时显示任务进度（可展开列表），没有时显示 core 下发的随机 tip，进入会话与发送消息时换一条。右侧依次是本会话改动（文件数 +/−）、子代理数、会话费用，各自有值才出现。变更 chip 点击仍切到变更分页；子代理与费用点击弹起对应 Popover（不离开对话区），上下文圆环同理弹上下文 Popover，「查看完整上下文」再进大尺寸模态。不放快捷键提示、cwd/分支（会话头已有）和运行态。
- 无描边、无聚焦态变化。唯一的状态描边是 `!` 命令模式的 `ring-warn/50`，表达模式而非焦点。
- 点击卡片空白处聚焦输入；拖拽文件时外层出现 `ring-brand/40`。
- 发送按钮：`size-8` 圆形、`bg-foreground` 反色，禁用时降为 tertiary。

### 浮层

- 菜单、下拉、右键菜单、`/` 与 `@` 补全统一：`rounded-xl bg-popover p-1 shadow-[var(--elevation-popover)]`，无 border。
- 分隔线 `bg-border-subtle`；分组标题 `text-xs font-medium text-muted-foreground`（补全里用 `text-2xs text-text-tertiary`）。
- 选中标记用 `muted-foreground` 的勾，不用强调色。
- 模态框 `rounded-2xl p-6`，标题 `text-heading`，描述 `text-ui text-muted-foreground`。

### 模型选择器

- 触发器只显示「模型 · 思考强度」，不带下箭头。
- 浮层左右两块：右侧可搜索列表（按供应商分组），左侧详情卡跟随列表高亮项，展示上下文、输出上限、图片输入、思考强度、Fast Mode 与价格。
- 只显示模型真有的信息：Fast Mode 开关只在模型配置 `fast_mode = true` 时出现；价格只在配置了 `pricing` 时出现，缺失就整段隐藏，不写「未知」。

### 徽标

- 用 `Badge variant="brand"`：`text-2xs`、`bg-brand/10 text-brand`。颜色随状态变化的才允许手写。

### 对话转写

- 用户消息：右对齐灰色气泡 `bg-bubble`，无边框。
- 助手正文直接落在主舞台上，不套卡片。
- 过程（思考、工具调用）默认折叠成一行 tertiary 摘要「处理用时 X · 活动摘要」，展开后左侧一条发丝线收纳。悬停只变文字色。

### 文件面板

- 右侧检查面板的默认分页；宽 ≥640px 时左树右编辑区并排（树宽 200–360 可拖，默认 240），更窄时编辑区替换树、头部给返回按钮。
- 树行高 `h-7`、`text-ui`、每级缩进 12px，只有极淡的缩进引导；目录 chevron + Folder/FolderOpen，文件按扩展名映射少量 lucide 图标，全部 muted 灰；agent 改过的文件行尾一个 brand 小圆点。
- 会话空间命名空间（计划 / 任务日志 / 工具归档 / 历史 / 技能）显示中文标签，行尾用 tertiary 等宽字回显原始 URI；整体只读。
- 编辑区标签条复用「选中 `bg-accent`、未选中只改文字色」的语言：预览标签斜体、未保存一个 brand 圆点、× 只在悬停浮现。
- CodeMirror 主题从令牌派生（Geist Mono、tertiary 行号、gutter 无描边、当前行极淡底色、选区 `--selection`、光标 brand）；Markdown 默认渲染 `.moc-prose` 预览，可切源码。

### 终端

- 终端分页整体懒加载（xterm 不进主包）。标签条复用文件标签的同一形态：标签名是 shell basename，非根 cwd 追加相对目录，已退出条目降为 tertiary 并显示退出码。
- xterm 视觉完全从令牌派生：背景与面板一致、光标 brand、选区 `--selection`；ANSI 16 色深浅各调一套，低饱和克制。容器只留内边距，不加边框。
- 快捷键 ``Ctrl+` ``：面板未开或不在终端分页时切过去，已在终端分页时收起面板。

### 工具与思考块

- 每个活动是一行 `h-7` 标题：图标 + 动词（`muted-foreground`）+ 目标（等宽 tertiary，单行截断）+ 右侧尾注（耗时、数量、`+N −M`）。没有卡片外框，也不加状态色描边；运行中靠动词脉冲表达，失败时图标换成警示图标，图标、尾注与错误行染成 `destructive`。
- 正文落在标题下方，和标题文字左对齐。容器统一用 `rounded-xl bg-code`，不加描边；终端、带行号代码、diff、grep 分组都放在这种灰底卡里，等宽 `text-xs`，行号槽和元信息用 tertiary。
- 档位决定露出多少，规则集中在 `lib/tool-view.ts`，组件只负责画：隐藏只留标题；简略按工具策略给少量预览（`read` 只有标题，`grep`／`find` 只报数量，`bash` 给命令和末尾 4 行，`edit`／`write` 给最多 6 行 diff）；完整显示全部。截断处给一个 tertiary 文字按钮「⋯ 还有 N 行」，点了展开成完整。
- 简略档的思考在流式时只露末尾几行，顶部用 mask 渐隐，不用分隔线。
- 同批次连续的同名只读工具合并成一行「读取 N 个文件」，展开后再逐个列出。

## 7. 正文排版（`.moc-prose`）

对话正文、思考内容、计划正文共用一套规则，元素通过 `data-streamdown` 标记命中样式；新增 Markdown 渲染场景必须复用 `.moc-prose`，用 `--moc-prose-size` 调字号，不另写排版。

- 正文 14.5px / 1.75 行高；标题无下边框，字间距 -0.01em。
- 行内代码：半透明底、4px 圆角、0.88em 等宽，跨行时 `box-decoration-break: clone`。
- 代码块：灰底大圆角，无语言头、无行号、无边框；复制按钮悬停才出现。
- 表格：只留水平发丝线，表头透明底、中等字重、次级色，首末列贴边。
- 引用：2px tertiary 左线 + 次级文字色。

## 8. 动效

- 只做状态过渡：颜色、透明度、`box-shadow`，时长约 120–200ms。
- 浮层进出用淡入 + 轻微缩放（模态框 0.98）。
- 不做几何跳变，不做装饰动画；运行指示只有三点呼吸，并尊重 `prefers-reduced-motion`。

## 9. 改动流程

1. 先查 `index.css` 有无可用令牌；没有就在浅色、深色两处同时新增，并写注释说明意图。
2. 组件里只用令牌类和字号阶梯，类名合并统一用 `@/lib/utils` 的 `cn`。
3. 浅色、深色都要截图确认，重点看对齐、层级是否反转、聚焦前后是否一致。
4. 提交前运行：`pnpm exec biome check src && pnpm exec tsc -b --noEmit`。
