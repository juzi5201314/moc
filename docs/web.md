# Web 前端使用说明

`moc web` 启动一个 core 进程 + 浏览器前端，并自动用系统默认浏览器打开 WebUI。
它和 `moc`（TUI）是平级的两个入口，不引入 daemon，也不做前后端分离的进程间转发：

```bash
moc web                       # 优先 127.0.0.1:7432，被占用则改用随机端口；随机令牌，自动打开浏览器
moc web --no-open             # 不自动打开浏览器（SSH / 无图形会话时也会自动跳过）
moc web --port 8080           # 指定端口；被占用直接报错，不静默换端口
moc web --port 0              # 一律由系统分配端口
moc web --token my-secret     # 固定令牌，方便脚本
moc web --cwd ~/project       # 指定工作目录（沿用 CLI 的 --cwd）
```

启动后终端会打印带令牌的 URL（`--port 0` 或回退到随机端口时，这里的端口才是实际端口）：

```
moc web 已启动：http://127.0.0.1:7432/?token=3f2a...
```

没自动弹出时手动打开即可。令牌缺失或错误时 WebSocket 握手返回 401。

端口只影响本次进程：同一台机器开多个 `moc web`（不同工作目录）时，后启动的会拿到随机端口，
互不阻塞。也正因为端口可能变化，浏览器里按 origin 存的界面偏好（主题、面板宽度、标签页）
只在端口不变时才延续；需要固定 origin 就显式传 `--port` 并先关掉占用它的实例。

## 能力

- 左侧工作区树管理多个本地目录与会话；搜索、新会话（`Alt N`）、命令面板（`Ctrl K`）
- 单会话工作台：转写与输入保持主焦点，侧栏独立切换会话；右侧检查面板按需打开（`Ctrl B`）
- 流式正文、折叠思考、按轮次收起的「处理过程」与工具卡片、diff、Markdown（表格、代码高亮、KaTeX 公式）
- Composer：运行中 Enter 补充到当前轮、`Ctrl Enter` 排队（本轮结束后自动发出）、`!` bash、斜杠命令、资源补全、图片输入
- 输入区底部切换模型 / 思考等级（`Alt M` 循环引擎仅限新会话）、计划模式（`Alt J`）、权限、自主程度与会话引擎
- 权限与提问卡片、计划审阅与逐行批注、回退（toast 里可「撤销」，走 `session/redo`）、手动压缩
- 右侧变更 / 计划 / 任务 / 子代理 / 上下文 / 用量 / 旁路
- 设置：按类别导航、改动即自动保存，全局 / 项目两层作用域；供应商只需填协议、地址与密钥，「从供应商获取」拉取 `/models` 候选，每个模型可单独编辑上下文、输出上限、思考等级、输入模态等元数据
- 目录选择器（`fs/list_dir` / `fs/create_dir`）浏览、新建目录后添加工作区；浅 / 深主题默认跟随系统
- 断线自动重连；会话共享与写租约规则保持不变

前端以 **React 单会话工作台**呈现：左侧以目录树管理工作区和会话，主区域专注于当前对话，右侧按需展开上下文、计划、Todo、变更、子代理或旁路。切换会话始终在同一主舞台进行，不提供占据主视线的会话标签条。

计划审阅面板默认停在「本版改动」：有上一版时先调 `session/plan_diff` 展示 `v{n-1} → v{n}` 的差异，没有上一版才回到正文。切到「完整计划」后可以按块悬停点「＋」批注整段，也可以拖选文字后点浮动条上的「批注」；编辑器里用 ```` ```suggestion ```` 围栏写出替换文本，「插入建议改法」会按所选源码行预填围栏。草稿只存在浏览器里，点「提交修改意见」时一次性交给 `session/plan_revise`，再把 core 生成的修订提示按普通提示发回模型；新版本随后以新的 `plan_id` 出现，面板沿 `previous_plan_id` 链自动跟到最新一版。

视觉与交互采用紧凑但留白充分的桌面工作台：中性低对比面板、明确的会话焦点、输入区固定在阅读流底部；功能沿用 moc 的会话、权限、流式更新与工具语义。

Web 作为 moc 的 Agent 工作台而不是 IDE：项目内文件阅读、变更与工具输出仍通过 agent 对话展开，优先让用户聚焦当前任务；工作区树只用于切换项目和会话，不额外引入一套文件编辑器。

### 自主程度

与 TUI 一致，每个会话有三档自主程度，可在输入区的权限菜单里切换，或用 `/autonomy [default|dont_ask|unattended]`（不带参数时循环）：

| 档位 | 行为 |
|---|---|
| 逐项确认（`default`） | 提问与计划都等你本人回应 |
| 自动作答（`dont_ask`） | 模型提问时由 core 按推荐项代答，计划仍需审阅 |
| 无人值守（`unattended`） | 在自动作答之上，本前端发起的提示产出计划后，自动「压缩上下文后执行」 |

新会话在发出第一条消息前只是本地草稿，所选权限与自主程度在 `session/new` 之后立即应用。

## 构建

前端采用 React 19、Vite 8、TypeScript、Tailwind CSS 4、shadcn/ui 与 Zustand；依赖由 pnpm 管理。服务启动后，前端使用同源 WebSocket JSON-RPC 连接 Core。
`build.rs` 在编译期把 `web/dist` 嵌入二进制，分发仍只需一个可执行文件：

```bash
pnpm --dir crates/moc-web/web install
pnpm --dir crates/moc-web/web build
cargo build --release --bin moc
```

嵌入前会把所有产物打成一条记录序列、整体压成单个 zstd 帧（19 级）：跨文件共享匹配窗口，
比逐文件压缩小约两成。`*.map` 不进二进制（`vite.config.ts` 也已关闭 sourcemap 生成），
调试前端用 `pnpm dev`。运行时首次请求解压归档，浏览器在 `Accept-Encoding` 里声明 zstd 时
响应带 `Content-Encoding: zstd`。

没有 `web/dist` 时 `cargo build` 仍能通过，但只嵌入一页「Web 前端未构建」提示；
设 `MOC_WEB_REQUIRE_DIST=1` 则直接构建失败（release CI 使用）。

开发时一个终端跑 `moc web --token dev --no-open --port 7432`，另一个跑 `pnpm --dir crates/moc-web/web dev`，
打开 `http://localhost:5173/?token=dev`（Vite 把 `/ws` 代理到 7432）。这里必须显式指定端口：
开发时端口是被代理的一方，静默回退会让前端连到空端口上。

## 连接模型：一个前端一个 core

每个前端进程内嵌一个 core：

| 命令 | 进程形态 |
|---|---|
| `moc` | TUI + core |
| `moc web` | Web 服务 + core |
| `moc --print` / `moc --repl` | 行式前端 + core |

浏览器标签页不是独立进程：同一个 `moc web` 下的所有标签页共享同一个 core 和同一张会话表。

- **同一 core 的多标签页**：同一会话可以被多个标签页同时打开；写互斥由 core 内的提示锁负责，第二个提示会收到 `SESSION_BUSY`。
- **跨 core 进程**：每个会话有一把跨进程写租约（Unix `flock` / Windows 命名互斥体），同一时刻只允许一个 core 进程持有。

## 跨进程写租约

写租约在以下时机获取：

- `session/new`（新会话）
- `session/load` 且 `read_only = false`
- 第一次发送提示（兜底）

租约持有到 `session/unload`（TUI 的 `/close`、Web 的「释放会话」）或**进程退出**；
内核在进程死亡时自动释放，不会留下需要手工清理的陈旧锁。

另一个进程以写模式打开同一会话时，core 返回 `-32015`，并在 `data.lock` 里带上持有者：

```json
{"lock":{"pid":12345,"frontend":"tui","process_name":"moc","acquired_at_ms":1760000000000}}
```

前端据此降级为**只读打开**：可以看历史，不能发提示或改会话状态。TUI 在状态栏显示
「只读」，Web 在标题旁显示「只读 · tui」并在输入区提示持有者。

`session/unlock` 只释放本进程持有的租约；别人持有时返回 `-32015`，不支持跨进程强夺。
要接管会话，请让持有者执行 `/close`、点「释放会话」，或退出那个进程。

只读打开不取租约，因此不会阻塞写者，也不会因为写者退出而失效；重新加载即可拿到写租约。

## 安全边界

- 只绑定回环地址 `127.0.0.1`（IP 不可配置），端口缺省 7432 / 占用时随机
- 访问令牌走 URL query，WebSocket 握手时校验；比较使用定长比较
- 浏览器带 `Origin` 时只接受本机来源，防 DNS rebinding 与跨站页面连入
- 令牌会出现在终端输出与浏览器地址栏；共享机器上建议用 `--token` 显式指定并妥善保管

## 与 TUI 的差异

| 能力 | TUI | Web |
|---|---|---|
| 流式正文 / 思维链 | 完整 | 完整 |
| 工具调用卡片 | 完整（diff、图表等） | 完整（结构化 diff、图表、按工具摘要） |
| 图片输入 | 支持 | 支持（当前模型声明 image 输入时） |
| 计划审阅 / 回退前滚 / 上下文窗 | 完整 | 完整（前滚通过回退后的「撤销」） |
| 自主程度 | 支持 | 支持（输入区菜单与 `/autonomy`） |
| 多会话 | 单会话 | 工作区树切换多个会话，同 core 共享，写互斥 |
| git 分支显示 | 支持 | 支持（`workspace/git_branch`） |
