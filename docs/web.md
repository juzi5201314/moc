# 浏览器界面（Web）使用说明

`moc web` 会启动一个本地服务并用默认浏览器打开界面，与终端 TUI 共用同一套配置和会话数据，无需单独部署后台服务。

## 启动方式

```bash
moc web                       # 默认监听 127.0.0.1:7432，被占用时改用随机端口并自动打开浏览器
moc web --no-open             # 不自动弹出浏览器（SSH 或无桌面环境也会自动跳过）
moc web --port 8080           # 固定端口；若被占用则直接报错
moc web --port 0              # 始终由系统分配随机端口
moc web --token my-secret     # 使用固定访问令牌（便于脚本或复用书签）
moc web --cwd ~/project       # 指定初始工作目录
```

启动后终端会打印带访问令牌的完整地址与日志路径：

```text
moc web 已启动：http://127.0.0.1:7432/?token=3f2a...
运行日志：~/.moc/web.log
```

运行日志默认写入 `~/.moc/web.log`（受 `MOC_HOME` 影响，启动时超过 8 MiB 自动轮转，可用 `RUST_LOG` / `MOC_LOG` 调整日志级别），不会在后台刷屏终端。

同一台机器可以同时打开多个 `moc web` 实例服务不同目录。由于浏览器按端口保存主题、侧栏宽度等本地偏好，若希望界面偏好持续保留，建议用 `--port` 固定端口。

## 主要功能

- **多工作区管理**：左侧目录树可同时挂载多个本地项目并管理各自会话，支持搜索、新建会话（`Alt+N`）与命令面板（`Ctrl+K`）。
- **单会话专注工作台**：中间为主对话区，支持代码高亮、表格、数学公式（KaTeX）、结构化改动预览与按轮次折叠的处理过程；左侧栏（`Ctrl+B`）和右侧检查面板（`Alt+R`）按需开合。
- **嵌入式交互组件**：在主对话中，模型可以直接生成 ```` ```widget ```` 交互页面，支持实时流式预览、源码切换、重置、复制、导出独立 `.html`、全屏查看与深浅主题联动；若脚本运行报错，可一键把错误填回输入框让助手修复。
- **右侧检查面板**：内置四个标签页——**Files**（浏览/编辑工作区文件、上传拖拽、删除到回收站，并只读查看会话空间内的 `plans`、`jobs`、`archive`、`history` 与 `skills`）、**Terminal**（内嵌持久终端，``Ctrl+` `` 开关）、**Changes**（集中查看文件改动）与**Aside**（不污染主对话的随时追问）。
- **计划审阅与逐段批注**：计划弹窗默认展示相对上一版的改动对比；切到完整计划可悬停段落点 `+` 或拖选文字写批注，也可插入建议修改块，一次提交给模型修订。支持当前会话执行、压缩后执行，或为新会话单独挑选引擎与模型执行。
- **工作流与子代理**：`/workflow` 激活后，侧栏会显示待审批/运行中徽标，提供可视化编排图、模型调整、产物浏览与停止/续跑；子代理结束后会以独立结果卡片留在对话中。
- **上下文检查与导出**：点击上下文圆环或输入 `/context` 可逐级查看发给模型的真实上下文构成（口径见 [上下文压缩与解释](../crates/moc-core/README.md#上下文压缩与解释)）；`/debuginfo` 与 `/session` 以纯本地只读卡片展示统计信息（口径见 [用户侧信息命令](../crates/moc-core/README.md#用户侧信息命令)）；`/export [path]` 将脱敏后的历史写为 Markdown，并在文件不超过 8 MiB 时自动触发浏览器下载。
- **附件与引用**：输入框左下「+」可上传任意本地文件，或用「Server files」直接选取 moc 所在机器上的文件（前后端不在同一台机器时尤其有用）。文件以 `#文件名` 引用，只把绝对路径与大小交给模型、由模型按需读取，不内联内容；上传文件存放在会话目录的 `uploads/` 下，同内容只存一份。图片仍作为图片输入，正文里用 `#1`、`#2` 指代第几张。`@路径`、`/命令`、`skill://` 等有效引用在输入框里显示为整体的小控件，复制粘贴后仍指向原内容。
- **实时配置同步**：设置页按分类组织，分为全局与项目两层，修改即时保存生效；供应商支持一键拉取模型列表并逐项调整元数据。

## 快捷键

macOS 下 `Ctrl` 组合同样支持使用 `Cmd`。

| 快捷键 | 功能 |
|---|---|
| `Ctrl+K` | 打开命令面板 |
| `Alt+N` | 新建会话并聚焦输入框 |
| `Ctrl+B` | 展开/收起左侧栏 |
| `Alt+R` | 展开/收起右侧检查面板 |
| ``Ctrl+` `` | 展开/收起右侧终端 |
| `Alt+P` | 打开模型选择器 |
| `Alt+M` | 切换会话引擎（首条消息发出后锁定） |
| `Alt+J` | 切换计划模式 |
| `Ctrl+O` | 切换工具显示档位（`Hidden` ↔ `Brief`） |

| `Esc` | 关闭补全菜单；输入框为空且运行中时停止当前生成 |

## 自主程度与显示档位

### 自主程度

在输入区权限菜单或通过 `/autonomy` 可为当前会话切换三档自主程度：

| 档位 | 行为 |
|---|---|
| `Default`（`default`） | 模型提问与计划审阅都需要你亲自确认 |
| `Don't ask`（`dont_ask`） | 模型提问时按推荐项自动代答，计划仍需你审阅 |
| `Unattended`（`unattended`） | 自动代答提问，并在产出计划后自动压缩上下文并开始执行 |

### 显示档位

可在「Settings → General → Appearance」调整默认显示档位（保存在 `~/.moc/web.toml`）。思考过程支持 **Hidden / Brief / Full** 三档；工具调用全局仅设 **Hidden / Brief**（`Ctrl+O` 切换），需要查看完整内容时直接点击对应卡片展开。

- `read`、`grep`、`find` 保持精简，只显示路径与计数，不平铺整段源码；连续的同名只读工具自动归并，带警告、图片或失败的调用独立显示。
- 截断提示、分页提醒、输出归档位置等警告在所有档位始终显示。
- 模型正在生成工具参数时，卡片会实时展示命令、脚本或编辑内容的生成预览，完成后无缝切换为正式执行卡片。

## 后台任务与内置终端

- **后台任务**：运行中的 `bash` 卡片会显示计时和实时输出，并支持一键转入后台。前台命令超过 60 秒自动转后台（默认每会话最多 8 个并行任务），120 秒无输出触发停滞提醒。输入 `/jobs` 可集中查看日志尾部或终止任务；刷新或重连浏览器不会丢失任务状态。后台任务送达模型的完成/停滞通知会以独立卡片保留在对话中。
- **手动命令**：输入框以 `!` 开头执行命令并记入上下文，`!!` 只显示不进上下文；两者均以 `full` 权限运行，不受当前会话沙盒约束。
- **内置终端**：右侧终端分页运行的是你本机的登录 Shell（不受代理沙盒限制，与系统自带终端权限一致），最多同时开启 32 个标签。刷新页面或切换面板不会杀掉终端进程，重连后自动回放最近输出；退出 `moc web` 时自动清理所有终端子进程。

## 多窗口协作与安全说明

### 多窗口与只读模式

- 同一 `moc web` 进程下的多个浏览器标签页共享同一会话状态；若两个标签页同时向同一会话发消息，后发出的请求会收到“会话忙碌”提示。
- 若某个会话已被终端 TUI 或另一个 `moc web` 实例打开编辑，当前窗口会自动以**只读模式**打开（标题旁标注来源），可以正常浏览历史、查上下文和做旁路问答，但无法发送消息或修改状态。要接管编辑权，在原窗口执行 `/close`、点击「Release lock」或退出原进程后再重新打开即可；原进程异常退出时系统会自动释放占用。

### 安全边界

- 服务仅监听本机回环地址 `127.0.0.1`，不对外网开放。
- 所有接口与 WebSocket 连接均校验访问令牌及本机 `Origin`，防止跨站页面连入。共享机器上建议使用 `--token` 指定私人令牌并注意保护地址栏链接。
- 嵌入式交互组件运行在隔离的沙盒 `<iframe>`（独立 `null` 源）中，无法访问主页面的令牌、DOM 或本地文件/终端接口，且仅在主对话助手回复中启用。

## 与终端 TUI 的主要差异

| 功能 | 终端 TUI | 浏览器 Web |
|---|---|---|
| 对话、思考、工具卡片、改动预览与图表 | 完整支持 | 完整支持 |
| 嵌入式交互组件（```` ```widget ````） | 历史中折为占位提示 | 完整交互预览、源码切换与导出 |
| 内嵌工作区文件编辑与多终端标签 | 不内置 | 右侧面板按需展开 |
| 多会话切换 | 单会话视图（`/resume` 切换） | 左侧多工作区目录树随时切换 |
| 计划审阅、回退/前滚、旁路问答、自主程度 | 完整支持 | 完整支持（回退后通过提示条「Undo」前滚） |

## 构建与前端开发

Web 前端基于 React 19、Vite 8、TypeScript、Tailwind CSS 4 与 pnpm，在 `cargo build` 期间由构建脚本自动编译并压缩嵌入 `moc` 二进制（要求 Node.js ≥ 22，前端文件未改动时跳过重建）。

前端本地热更新调试：

```bash
# 终端 1：固定端口启动后端（Vite 代理默认指向 7432）
moc web --token dev --no-open --port 7432

# 终端 2：启动前端开发服务器，随后访问 http://localhost:5173/?token=dev
pnpm --dir crates/moc-web/web dev
```
