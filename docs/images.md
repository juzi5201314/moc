# 图片发送与请求体诊断

TUI 粘贴、WebUI 上传、`@图片路径`、ACP、MCP/工具结果中的内联图片，在进入供应商 HTTP 请求前共用 `moc-llm` 的预处理。恢复旧会话也使用这条路径。只修改请求副本，原始会话中的图片不被重编码或删除；上下文查看使用相同处理结果。

## 单图处理

- PNG、JPEG、GIF、WebP、BMP 解码后按实际格式处理，不能用错误 MIME 绕过检测。
- 单张输入最多 20 MiB、解码像素最多 6400 万；解码失败在本地报错，不把坏图或原始大图继续发给上游。
- 应用方向信息，保持纵横比，不放大小图；初始预览上限为 `1568 × 1568` 总像素、最长边 8192 px。总像素限制避免长截图仅因长边超限就把短边缩到很小。
- 单图编码目标 500 KiB。尺寸合规且不超过当前字节预算与 125 KiB 中较小者时，可保留原始编码。
- 其余图片比较原始合规编码、PNG 和 JPEG；JPEG 质量按 85、75、60 逐级尝试。含真实透明像素时比较 PNG 与无损 WebP，不丢弃透明度。
- 仍然超预算时，尝试初始预览的 85%、70% 边长；达到尺寸/质量下限仍不够则明确报错，请用户裁剪关注区域或分批处理。这个下限限制质量损失，但不代表任意截图上的小字都必然清晰。

压缩在阻塞工作线程执行，客户端最多两个发送准备任务并行；缓存最多 32 个结果、合计 24 MiB。缓存键包含图片内容摘要和字节目标，不会每轮重复压缩相同图片，也不会从上一轮的有损版本继续压缩。

远端 HTTP(S) 图片 URL 保持 URL，不由客户端下载；其实际图片体积不包含在内联字节预算中，诊断会明确列出这类图片数量。`data:…;base64,…` URL 则与普通 Base64 图片使用相同处理。

## 多图与历史图片预算

单图预算并不能约束一整个上下文。发送前会统计**全部当前图片、历史图片、工具结果图片以及重复出现的图片**：

1. 对每张图执行单图处理。
2. 编码真实的供应商请求，扣除文本、工具定义、协议封套所占字节。
3. 图片 Base64 合计最多 8 MiB，同时不能超过请求体剩余空间。小图先满足其所需空间，剩余额度在大图之间均分。
4. 如需进一步压缩，从原始图片重新生成；不静默删掉旧图片或当前图片。
5. 按最终 HTTP 请求体精确字节数再次校验。不能满足预算则本地失败，网络请求不会发出。

默认完整请求上限为 50 MiB。网关限制更小时，在具体模型条目设置，例如：

```toml
[providers.my-provider.models.my-model]
max_request_bytes = 2097152 # 整份请求 2 MiB；包括历史、工具定义、图片与 JSON
```

15 张各 500 KiB 的图片，Base64 约 9.77 MiB，不能直接叠加发送；8 MiB 总图片预算会把较大图片的目标调低至平均约 409.6 KiB 原始编码字节。实际压缩结果通常更小。数量更大或网关预算更小时，不能同时保证无限图片数量和无限细节；达到质量下限后会提示分批、裁剪、压缩历史或调整请求上限。

正常的历史摘要/归档仍可能按原有压缩语义移除图片；这与为 HTTP 字节预算静默淘汰图片不同。

## 524 / 413 与请求诊断

其他标准、非标准状态码的中文说明与显示规则见 [HTTP 错误显示](http-errors.md)。

HTTP 错误文本（TUI 和 WebUI 共用）会附带：

- 最终请求体字节数、KiB 数值和本地请求上限。
- 图片总数、历史图片数、远端 URL 数量。
- 图片 Base64 处理前后字节数、非图片请求部分字节数。
- 等待时长、供应商请求 ID，以及上游提供时的 Cloudflare `cf-ray`。

**413** 是上游明确拒绝请求体大小；应按网关限制调整 `max_request_bytes`。

**524** 是 Cloudflare 使用的超时状态码，不是图片专属错误，也不是请求体超限的判据。[官方说明](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-524/)列出两种情况：与源站已连接，但等待 HTTP 响应超过 Proxy Read Timeout（当前默认 125 秒）；或者向源站写入数据超过 Proxy Write Timeout（通常 30 秒）。源站负载、处理耗时、传输阻塞等都需要结合日志确认，不能仅凭是否含图或约 30 秒的耗时确定原因。

含图和无图的 524 都按已有 `Timeout` 重试策略及配置预算处理。请求体与图片统计只提供排障事实，不用于改变超时的归因或重试资格；不会自动删除图片后再请求。
