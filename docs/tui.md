# 终端界面（TUI）使用说明

## 界面布局

终端界面自上而下分为五个区域：

1. **顶部信息条**：品牌、Git 分支、工作目录，右侧为上下文用量进度条和会话费用。
2. **对话转写区**：显示对话正文、思考过程、工具调用、改动预览、表格图表与内联图片；有任务清单时，右上角悬浮任务卡片（Todo HUD）。
3. **待发送区**：运行中插队或排队的输入会暂存在输入框上方，发出前可随时点击改回或丢弃。
4. **底部输入框**：支持多行自动增高、斜杠命令补全、历史召回、粘贴摘要与图片；下边框左侧显示快捷键提示，右侧显示当前模型与模式。
5. **状态栏**：左侧显示当前运行状态（`Working`、`Thinking`、`Responding`、`Running`、`Waiting`、`Stopping`），右侧显示本会话累计用量与输出速率。

默认采用深色配色，启动时自动适配终端的真彩色、256 色或 16 色能力。

## 鼠标与通用操作

- **滚动与滚动条**：支持滚轮滚动与右侧滚动条拖拽；指针移到最右侧两列时，滚动条自动加宽便于抓取，移开后恢复细条。
- **点击折叠/展开**：点击思考块、工具卡片或代理消息的标题，可在「完整展开」与「当前全局档位」之间切换。
- **拖选与复制**：在对话区或输入框内拖选文本后，按 `Ctrl+C`、右键或 `y` 复制（同时写入终端与系统剪贴板）。按住 `Shift` 拖选可临时交由终端自身接管。输入框有选区时，`Esc` 优先取消选区。
- **直接点击提示与菜单**：底部与卡片上标注的单键提示（如 `Esc Close`、`Enter Confirm`、`Shift+X Skip`）均可直接点击；点击输入框右下角的模式名可弹出模式切换菜单。
- **弹窗外点击**：帮助、上下文、模型、会话、子代理与回退等浏览类弹窗，点空白处即可关闭；权限确认、提问和计划审阅等需要决策的弹窗不会因误点外部关闭。

## 常用快捷键

| 按键 | 功能 |
|---|---|
| `Enter` / `Ctrl+Enter` | 发送（运行中默认插队补充）/ 排入后续队列 |
| `Shift+Enter` / `Alt+Enter` | 输入框换行 |
| `↑` / `↓` | 补全菜单上下选择；否则翻阅输入历史或多行移动光标 |
| `Tab` | 确认补全；否则在对话区与输入框间切换焦点 |
| `Ctrl+P` / `Shift+Tab` | 打开模型选择器 / 快速切换思考等级 |
| `Alt+M` | 切换会话引擎（或点击右下角模式名） |
| `Ctrl+T` / `Ctrl+O` | 切换思考显示档位 / 切换工具显示档位 |
| `Ctrl+G` | 打开设置页 |
| `Ctrl+R` | 恢复历史会话（列表内按 `Tab` 在当前目录与全部目录间切换） |
| `Ctrl+N` / `Alt+A` | 打开子代理侧栏 / 显隐子代理侧栏 |
| `Alt+B` | 展开或收起旁路问答面板 |
| `Ctrl+V` | 粘贴剪贴板图片或文本（优先图片） |
| `Alt+↑` | 将最近一条待发送消息撤回输入框重新编辑 |
| `Ctrl+H` | 查看快捷键帮助（随设置里的改键同步更新） |
| `Ctrl+C` | 有选区时复制；运行中停止当前任务（连按两次退出）；空闲时清空或退出 |
| `Esc` | 取消选区 → 停止生成 → 清空输入 → 空输入框双击打开消息回退；聚焦子代理时返回主会话 |
| `←` `←` | 聚焦子代理时连按两次返回主会话 |

运行中输入框有内容时，输入框下边框左侧的提示从 `Esc Stop` 换成排队键位（如 `Ctrl+Enter Queue`；开启 `queue_on_enter` 时显示为 `Ctrl+Enter Steer` / `Interrupt`），点击它与按键同义。

> 部分终端无法区分 `Ctrl+Enter` 或 `Ctrl+M`（会视为普通 `Enter`），可在 Settings 的 `UI` 页签中重新绑定快捷键。WSL 经 ConPTY（Windows Terminal 等）运行且终端不支持 kitty 键盘协议时，moc 会开启 win32-input-mode，使 `Shift+Enter` / `Ctrl+Enter` 可区分；`/doctor` 的 Keyboard 一行显示当前协议，`MOC_WIN32_INPUT=0|1` 可强制关闭或开启。`tui.toml` 只保存改动过的键位，其余跟随内置默认。

有效引用在输入框里显示为「图标 名称」的整体控件（accent 前景 + 抬升底色）：光标整体跨过、退格整体删除、折行不拆开，发送与复制的仍是原始文本。成形的范围：开头的已注册 `/命令`、存在的 `[image#N]` / `[paste#N]` 占位，以及经 `resource/inspect` 确认有效的 `@路径` 与 `skill://` 等资源 URI（按会话缓存校验结果，30 秒复验一次）。逐字输入中的 token 不成形，敲空格或移开光标后才会变为控件。会话已发送消息里的 `[file]` / `[dir]` / `[#name]` / `[image#N]` 附件标记在转写中以同一套控件样式回显。

## 斜杠命令与手动命令

输入框仅对已注册的命令（内置命令、别名及已加载插件命令）成形为「`/` 命令名」控件，未知的 `/xxx` 按普通文本原样发送。以 `!` 开头会直接运行 Shell 命令并把输出写入对话上下文；以 `!!` 开头只在本机执行并显示结果，不发给模型。用户亲手输入的 `!` / `!!` 命令始终以 `full` 权限运行，不受会话沙盒限制。

| 命令 | 说明 |
|---|---|
| `/help` | 打开快捷键与命令帮助 |
| `/config`、`/settings` | 打开设置页（修改实时保存并生效，支持 `Ctrl+Z` 撤回、`Ctrl+Y` 重做） |
| `/model` | 切换模型与思考等级（若目标模型窗口装不下当前上下文，会先询问是否压缩） |
| `/engine`、`/clm-experimental` | 在会话发出第一条消息前切换引擎（`standard` / `ptc` / `clm`） |
| `/plan [prompt]` | 进退 plan 模式；带 prompt 时直接进入并发送该需求 |
| `/confirm-plan` | 重新打开当前待审阅的计划窗口 |
| `/ask <question>` | 仅本轮以只读方式提问，结束后自动恢复原模式 |
| `/autonomy` | 切换自主程度：`default`（逐项确认）、`dont_ask`（自动代答提问）、`unattended`（同时自动批准计划并压缩执行） |
| `/btw [question]` | 打开或追问旁路问答面板 |
| `/goal [subcommand]` | 设定会话持久目标，自动多轮推进直到完成或遇阻；支持 `pause` / `resume` / `edit` / `clear` |
| `/retry` | 从当前 context 继续执行；若上一轮被中断或出错，会先自动清理半截回复后再续跑 |
| `/compact` | 手动压缩 context |
| `/context` | 打开 context 占用明细面板 |
| `/tools` | 查看下一轮请求实际开放给模型的工具列表 |
| `/usage` | 查看各 model 调用次数、token 用量、缓存命中率、首字延迟与输出速率 |
| `/debuginfo`、`/session` | 查看工具统计与压缩次数 / session ID、日志路径与存储占用（不发给模型，口径见 [用户侧信息命令](../crates/moc-core/README.md#用户侧信息命令)） |
| `/export [path]` | 导出 session 历史为 Markdown（自动脱敏常见密钥，不覆盖已有文件） |
| `/jobs` | 打开后台任务弹窗（`x` 连按两次终止选中任务） |
| `/agents` | 打开 subagent 侧栏 |
| `/plugins [reload]` | 查看已加载 plugin 及错误原因；`reload` 重新加载并恢复被停用的 plugin |
| `/workflow [instruction]`、`/workflows` | 在当前 session 激活 workflow / 打开 workflow 运行列表 |
| `/features` | 查看各项特性的启用状态、阶段与大致上下文开销 |
| `/new`、`/resume`、`/close`、`/quit` | 新建会话 / 恢复会话 / 卸载会话并释放编辑占用 / 退出 |

依赖已关闭特性的命令不会出现在自动补全中，在 `/help` 中会标明「特性已禁用」。

## 运行中输入与消息回退

- **运行中继续发消息**：
  - 按 `Enter` 默认「插队」补充要求，等当前模型响应或工具批次收尾后、下一轮请求前自动合入。
  - 按 `Ctrl+Enter` 将消息排入「队列」，等本轮完整结束后依次发出。
  - 也可在 `Settings → UI` 中将 `Active Submit` 改为 `interrupt`（中断当前任务并重新提交）。
  - 开启 `Queue on Enter`（`queue_on_enter = true`）后两者互换：`Enter` 排队，`Ctrl+Enter` 按 `Active Submit` 插队或中断；输入框图例与快捷键一览同步改写。
- **原地回退与前滚**：输入框为空且会话空闲时连续按两次 `Esc`，可浏览消息时间线并原地截断到任意位置（不改会话 ID，选中用户消息时会把原文填回输入框便于修改）。刚截断的尾部会暂留在列表下方，按 `Enter` 可随时前滚接回；写入新消息后可前滚记录即清空。
- **重答提问**：在回退列表选中含模型提问的条目按 `R`，会重新弹出原提问卡片，改选答案后继续推进。

## 计划审阅与提问卡片

### 计划审阅

计划模式下，模型起草并提交计划后会自动弹出审阅窗口，包含三个标签：

- **Changes**（`d` 切换）：存在上一版计划时默认展示本版差异。
- **Plan**：浏览排版后的计划，悬停段落点 `+` 或拖选多段即可写批注。
- **Source**（`a` 切换）：带行号的原文视图，`v` 选行、`c` 写批注、`Ctrl+G` 插入建议改法代码块。

批注写好后按 `s` 一次性交回模型修订。底部可选择 `Keep planning`、`Submit notes`、`Run`、`Compact & run` 或 `Run in new session`；选择新会话执行时，按 `n` / `e` 可单独指定新会话的模型和引擎，不影响当前会话。按 `Esc` 暂时关闭窗口后，随时可用 `/confirm-plan` 重新打开。

### 提问卡片

模型向你提问时，居中弹出卡片，推荐项默认高亮，直接按 `Enter` 即可采纳：

- `1`–`9` 直达选项，`Space` 勾选多选，`z` 跳至自定义输入行，`y` 复制当前聚焦项。
- 多问场景下用 `←`/`→` 翻看各题、`Tab`/`Shift+Tab` 切换推进，全部答完后统一提交。
- 按一次 `Esc` 可将卡片「停泊」以便翻看上方对话记录（再按 `Tab`/`Enter` 回到作答，再按一次 `Esc` 取消）；`Shift+X` 跳过整单，`Ctrl+C` 取消。

## 显示档位

思考过程支持三档（`Ctrl+T` 切换：**`hidden` → `brief` → `full`**）；工具调用全局支持两档（`Ctrl+O` 切换：**`hidden` ↔ `brief`**），查看完整工具结果请直接点击对应卡片标题。启动时可用 `--detail hidden|brief|full` 临时覆盖（其中 `full` 仅展开思考块）。

| 档位 | 思考块 | 工具卡片 |
|---|---|---|
| `hidden` | 单行标题（含耗时与速率） | 单行标题摘要；警告、截断与归档提示仍直接显示 |
| `brief`（默认） | 末尾 4 行预览 | `bash` 展示命令与末尾 4 行输出；改动预览最多 6 行；`read`/`grep`/`find` 只显示路径与计数；`todo` 展示前三项与后两项 |
| `full` | 完整思考正文 | 仅限点击单条工具展开（单条长输出最多展示 4001 行） |

切换全局档位会自动收回该层所有手动展开的卡片。

## 旁路问答 `/btw`

主任务进行期间，可在同一输入框输入 `/btw 你的问题` 打开独立旁路面板（宽屏在右侧，窄屏在下方），继续追问只需再次输入 `/btw 新问题`，单独输入 `/btw` 可重新呼出面板。

- 旁路问答读取当前会话的模型与上下文快照，但不调用工具，不写入主会话历史或用量统计；只读打开的会话也能使用。
- 每个会话最多在内存中保留最近 20 轮问答，退出程序后清空。
- 常用键位：`Alt+B` 显隐并聚焦，`Tab` 在主输入与旁路间切换，旁路聚焦时 `Esc` 收起不中断生成、`Ctrl+C` 仅取消旁路、`c` 复制最新回答、`x` 清空记录。

## 后台任务、子代理与工作流

- **后台任务**：前台 `bash` 运行超过 60 秒自动转入后台，标题附 `· bg job_X` 徽标（每会话默认上限 8 个并行任务）；120 秒无输出触发停滞提醒。后台任务结束时，若会话空闲会自动唤醒模型继续处理。用 `/jobs` 查看进度或终止任务（详情见 [docs/limits.md](docs/limits.md)）。
- **子代理**：模型创建子代理后，宽屏下右侧自动弹出子代理侧栏。点击任意子代理卡片可将整个界面切换到该子代理，直接发消息交互或按 `Ctrl+S` 停止；按 `Esc`（空输入框）或双击 `←` 返回主会话。子代理结束后，结果会以独立卡片保留在主对话中。
- **工作流**：激活后若有待审批或运行中的工作流，输入框下沿会出现状态徽标，点击可打开审批窗或运行面板（详见 [docs/workflow.md](docs/workflow.md)）。

## 表格图表、流程图与内联图片

- **表格一键绘图**：在支持终端图形协议（kitty / sixel / iTerm2）的终端里，助手回答中的顶层表格下方会出现 `▸ Show chart`，点击后按数据特征自动生成条形图、折线图、热力图、散点图或分面图（宽度上限 720px），再次点击隐藏。可通过 `MOC_CHART_FONT` 指定字体、`MOC_CHART_GRAPHICS=kitty|sixel|iterm2|none` 强制协议、`MOC_CHART_CELL=8x18` 校准单元格像素尺寸。
- **内联图片与 SVG**：工具返回的图片、正文里的本地图片链接以及 `svg` 代码块会在支持的终端中直接渲染（工具图片最多展示 4 张，超出以摘要提示）；不支持图形协议的终端自动回退为文字或代码高亮。SVG 渲染仅允许内嵌资源，不读取外部本地文件。
- **Mermaid 流程图**：`flowchart`、`graph`、`sequenceDiagram` 与 `stateDiagram` 围栏闭合后会自动渲染为字符图；其他图种保留代码高亮。

## 上下文面板、任务卡片与状态栏

- **上下文面板（`/context`）**：展示发给模型的真实 token 分布（`system`、`AGENTS.md (p+g)`、`skills`、`tools`、`messages` 及 `plugins`，分类口径见 [上下文压缩与解释](../crates/moc-core/README.md#上下文压缩与解释)）。支持逐级钻取查看原文、切换纯文本、翻页（`p`/`n`）与复制（`y`）；打开时冻结快照，会话变化后按 `r` 刷新。工具输出及超过 2,000 字符或 80 行的超长用户输入仅统计用量、不展开正文。
- **悬浮任务卡片（Todo HUD）**：存在待办清单时悬浮在对话右上角，单击可折叠为单行胶囊，按住可拖拽调整位置。模型或推理等级被上游改写时，右上角会短暂弹出橙色告警胶囊，任务卡片自动下移避让。
- **自定义状态栏**：可在 `~/.moc/tui.toml` 配置 `statusline` 模板，例如：
  ```toml
  statusline = "{model} * {status} -> {workdir}"
  ```
  可用占位符：`{model}` `{status}` `{context}` `{context_percent}` `{workdir}` `{branch}` `{todo}` `{tokens_in}` `{tokens_out}` `{tok_s}` `{prompt_elapsed}` `{cost}`。

## 剪贴板与历史输入

- `Ctrl+V` 在 Linux 上依赖 `wl-paste`（Wayland）或 `xclip`（X11）；WSL 自动读取 Windows 剪贴板；macOS 优先使用 `pngpaste`，未安装时自动调用系统内置能力，无需额外配置。
- 提交过的普通消息、斜杠命令（不含 `/btw`）和 `!` 命令会保存在 `~/.moc/tui-history.jsonl`（默认全局共享，可在 `Settings → UI` 中将 `History Scope` 切换为 `project` 仅限当前项目，最多召回最近 200 条）。
